# Architecture Decision Records

Use one numbered Markdown file per significant decision. Each record should state its status, context, decision, and consequences. Proposed decisions may be revised; accepted decisions should be superseded by a new record rather than silently rewritten.

Current records include the NLopt worker spike in ADR 0006, the SciPy/Pyodide
worker spike in ADR 0007, and the accepted NLopt production decision in ADR 0008.
